# Atharva Borawake — AI/ML Portfolio

Static personal portfolio built with **HTML5, CSS3 and vanilla JavaScript**.

## Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── resume.pdf
│   └── favicon.svg
└── README.md
```

## Run locally

Open `index.html` directly in a browser, or use any simple static server.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository's `main` branch.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select **main** and **/ (root)**.
6. Save.

No build command or backend is required.

## Before publishing

Update the two profile URLs in `script.js`:

```js
const PROFILE_LINKS = {
  github: "https://github.com/yourusername",
  linkedin: "https://www.linkedin.com/in/yourusername/"
};
```

The project GitHub/live-demo links are intentionally omitted because no verified repository/demo URLs were supplied. Add them only when they exist.

The contact form uses `mailto:` and therefore opens the visitor's email client instead of pretending to have a backend.
